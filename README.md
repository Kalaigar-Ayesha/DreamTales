# 🌙 DreamTales

**DreamTales** is a fun and magical storytelling web app that helps parents create personalized, emotion-based stories for their kids using AI. Whether your child feels scared, happy, or curious — DreamTales generates just the right story to match their mood.

Built with ⚡ Vite, 💙 React + TypeScript, ✨ Tailwind CSS, and powered by ✨ Gemini AI and Supabase, DreamTales is fast, beautiful, and easy to use — on any device.

---
🔗 Live Demo
👉 Visit DreamTales Live : https://dream-tales-umber.vercel.app
Create your own story in just a few clicks!


## ✨ Key Features

* 🧠 **AI-Powered Stories** – Uses Gemini API to generate mood-based stories
* ⚛️ **React + TypeScript** – For clean, type-safe UI
* 🎨 **Tailwind CSS + shadcn/ui** – Responsive, modern, and elegant design
* ☁️ **Supabase Auth + DB** – Simple login and secure story storage
* 📱 **Mobile-Friendly** – Works great on phones and tablets
* 🚀 **Built with Vite** – Super fast dev and build experience

## 📦 Installation

1. **Clone the project**

   ```bash
   git clone <your-repo-url>
   cd DreamTales
   ```

2. **Install dependencies**

   ```bash
   npm install
   # or
   yarn install
   ```

---

## 🛠️ Run Locally

To start the development server:

```bash
npm run dev
# or
yarn dev
```
