# DreamTales

DreamTales is a modern web application for creating magical, emotion-based stories for children using AI. Built with Vite, React, TypeScript, shadcn/ui, Supabase, and Tailwind CSS, it offers a fast, beautiful, and highly interactive user experience.


## Features
- **Vite** for lightning-fast development and builds
- **React + TypeScript** for robust, type-safe UI
- **shadcn/ui** for accessible, customizable UI components
- **Supabase** integration for backend and authentication
- **Tailwind CSS** for utility-first styling
- **Responsive** and mobile-friendly design


### Installation
1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd DreamTales
   ```
2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

### Development
To start the development server:
```bash
npm run dev
# or
yarn dev
```
